## Ubuntu terminal theme

- Add the built-in **Ubuntu 22.04** theme with a black background, white text, and the ANSI palette captured from a local Ubuntu 22.04 GNOME Terminal profile, including its customized blue. Application controls use an Ubuntu orange accent.
- Use Ubuntu 22.04 by default for new configurations and configurations without a theme. Existing saved theme choices remain unchanged; `--theme` still overrides the theme for one run.
- Choose the theme with **t** in the connection manager or **Ctrl+] t** in a remote terminal, then press Enter to save. It is also available through `ssh-tui --theme "Ubuntu 22.04"`.
- Expand the theme picker to 13 built-in themes and update English and Chinese responsive UI snapshots and interactive acceptance coverage.

## Ubuntu 终端主题

- 新增内置 **Ubuntu 22.04** 主题：黑底白字，采用本机 Ubuntu 22.04 GNOME Terminal 的实际 ANSI 配色（包含自定义蓝色），界面使用 Ubuntu 橙色强调。
- 新配置及未指定主题的配置默认使用 Ubuntu 22.04；已有配置中明确保存的主题保持不变，命令行 `--theme` 仍可临时覆盖。
- 在连接列表按 **t**，或在远端终端按 **Ctrl+] t**，选择主题后按 Enter 保存；也可通过 `ssh-tui --theme "Ubuntu 22.04"` 启动。
- 内置主题增加至 13 个，同步更新中英文响应式界面快照与交互验收。

## Downloads

Packages are provided for Linux x86_64, macOS Intel, and macOS Apple Silicon. Verify the archive against `SHA256SUMS` before extracting. macOS binaries are not signed or notarized.
