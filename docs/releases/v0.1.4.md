## Linux image paste

- Enable image paste per SSH tab with **Ctrl+] v**, then press **Ctrl+V** to upload a local clipboard image and insert its remote path. Enter is never sent automatically. New and reconnected sessions start with this mode off.
- Supports PNG and JPEG up to 20 MiB. Install **xclip** on X11 (`sudo apt install xclip`) or **wl-clipboard** on Wayland (`sudo apt install wl-clipboard`). These are optional system dependencies and are not installed by the installer.
- Reuses the authenticated SSH connection, including saved credentials and HTTP proxies; transfer failure never falls back to a direct connection. Press Esc to cancel a pending paste.
- Successful images remain in private `/tmp/ssh-tui-image.*` directories on the remote host for later use; remove them when finished or rely on the host temporary-file policy.
- Adds bilingual help, clipboard/upload acceptance coverage, and keeps the disconnected-session hint visible in narrow terminals.

## Linux 图片粘贴

- 在 SSH 标签页按 **Ctrl+] v** 开启图片粘贴，再按 **Ctrl+V** 上传本地剪贴板图片并插入远端路径；不会自动发送回车。新建或重连会话默认关闭。
- 支持 PNG/JPEG，最大 20 MiB。X11 需安装 **xclip**（`sudo apt install xclip`），Wayland 需安装 **wl-clipboard**（`sudo apt install wl-clipboard`）；安装脚本不会自动安装这些可选系统依赖。
- 复用已认证 SSH 连接，兼容保存的凭据和 HTTP 代理；传输失败不回退直连。按 Esc 可取消正在进行的粘贴。
- 成功上传的图片保留在远端私有 `/tmp/ssh-tui-image.*` 目录，使用后由用户或系统临时文件策略清理。
- 补充中英文帮助、剪贴板及上传验收，并修正窄终端下断线提示被遮挡的问题。

## Downloads

Linux x86_64 only. Verify the archive against `SHA256SUMS`. macOS image paste is not supported.

仅发布 Linux x86_64 安装包，请使用 `SHA256SUMS` 校验；图片粘贴不支持 macOS。
